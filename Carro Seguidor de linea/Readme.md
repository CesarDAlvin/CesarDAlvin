## 🛠️ Requisitos

### Hardware

* Placa Arduino (Uno, Nano, Mega, etc.)
* Sensor QTR-8A (6 sensores IR)
* Cables y protoboard

### Software

* Arduino IDE (versión 1.8.x o superior)
* Python 3.x (opcional para análisis de datos)
